# Peugeot Sport — A Motorsport History

An interactive, scroll-transforming motorsport exhibition showcasing four decades of **Peugeot Sport** — from the 1981 Group B rally revolution to the modern FIA WEC **9X8 Hypercar**.

## Highlights
- **Intro Video → Official Peugeot Sport Splash**: Full-viewport intro video dissolving under the official 2021 Peugeot coat-of-arms lion shield and Peugeot Sport wordmark.
- **Scroll-Transforming Era Liveries**: Each section transforms the entire viewport palette, diagonal livery graphics, historical Peugeot emblems, and blended champion portraits across eight eras:
  1. **2022 — Today**: The 9X8 Hypercar Project (FIA WEC)
  2. **1981 — 1986**: Group B Glory (`205 Turbo 16` & `Evo 2`)
  3. **1987 — 1990**: Desert & Mountain (`205 T16 Grand Raid` & `405 T16 Pikes Peak`)
  4. **1990 — 1993**: The `905` at Le Mans (Group C V10)
  5. **1994 — 2000**: Formula 1 V10s (McLaren, Jordan, Prost)
  6. **1999 — 2005**: The `206 WRC` & `307 WRC` Years
  7. **2007 — 2011**: Diesel Thunder (`908 HDi FAP` & `908` LMP1)
  8. **2013 — 2018**: Return to the Extremes (`208 T16 Pikes Peak` & `3008 DKR`)
- **Side-Burst Transparent Car Cutouts**: Unboxed high-resolution race car cutouts rocket onto the stage from alternating sides with scroll-linked drift and speed-streak accents.

## Run Locally
Serve the directory with any static HTTP server:

```bash
python -m http.server 5173
```

Then open `http://localhost:5173`.
